about=ArtefactJugaad is a QGIS tool for correcting spatial artefacts in raster datasets. It supports two correction approaches: Reference Raster correction, where artefact pixels are replaced using a corresponding reference raster, and Interpolation correction, where pseudo-values within artefact polygons are reconstructed from surrounding valid raster pixels using GDAL interpolation. The Raster to Correct is always treated as the master raster, preserving its CRS, pixel size, extent, dimensions and grid alignment. Multiple artefact polygons are supported.
